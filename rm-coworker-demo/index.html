Extending RM Coworker

RM Coworker preps the call. Nobody owns what happens after.

Relationship managers get faster call prep and sharper insights from RM Coworker today. The follow-through — the email, the CRM note, the cross-sell flag — is still manual, still inconsistent, and still where revenue quietly leaks. This prototype closes that gap.

The foundation

Same architecture as every OBZ AI Coworker — this agent is a configuration on top of it, not a new build.

Follow-Up Agent, on the standard base

Inherits RM Coworker's existing enterprise access. Nothing new to integrate.

Knowledge

Reuses what RM Coworker already has:

  • Client history & portfolio
  • Product & pricing catalog
  • Compliance / suitability rules
Channels

Acts where the RM already works:

  • Draft in email
  • Note in CRM
  • Slack/Teams ping to RM
Skills

New skill added to the base:

  • Summarise the call
  • Draft the follow-up
  • Flag cross-sell + next-best-action
Tools

Same tool access, no new setup:

  • Salesforce / core CRM
  • Email
  • Calendar / task queue

How this gets sold

        
Not a new pitch to a new buyer. This goes to the existing RM Coworker sponsor as: "the workflow you already trust, extended one step further, with zero new integration."

        
    
          
  • Angle: quantify what's leaking today (missed cross-sell on long-tail accounts) using the client's own account volume
    • 
          
  • Proof: one pilot desk, 4–6 weeks, measured against baseline follow-up rate
    • 
          
  • Close: same procurement motion as the original RM Coworker deal — no new vendor review
    • 
        

      

      

        
What I'd explicitly not do

        
Not pitching this as a new AI product to a cold bank. That's a 6–12 month enterprise cycle this prototype can't shortcut.

        
    
          
  • Not chasing a brand-new bank relationship — no warm door, no case study to point to yet
    • 
          
  • Not automating the credit-line or compliance-sensitive decisions — those stay human-in-the-loop, routed not resolved
    •
