## Projects

### RM Coworker Follow-Up Agent — OBZ Demo
**Live prototype showing how OneByZero's RM Coworker closes the post-call workflow gap**

The problem: Bank relationship managers spend time on call prep (handled by RM Coworker today), but 80% of follow-through remains manual — drafting emails, logging CRM notes, identifying cross-sell opportunities.

The solution: An AI-powered Follow-Up Agent that reuses RM Coworker's existing enterprise access to automatically generate contextual follow-ups, route for compliance review when needed, and flag upsell opportunities.

**What this demonstrates:**
- Real function calling — the agent genuinely looks up client data, call transcripts, and compliance flags via mock tools
- Scoped business case — unit economics grounded in actual RM workflows (2.5 hrs/week saved per RM, ₹50–100K/month pricing, <6 week payback)
- Reusable architecture — configured on OBZ's standard AI Coworker foundation (Knowledge/Channels/Skills/Tools), not a one-off build
- Ready to present — live demo that shows the workflow, tool traces, and business model

**Try it:** Visit the [rm-coworker-demo](./rm-coworker-demo) directory. Run `npm install && npm start`, then open http://localhost:3000 to see it in action.
